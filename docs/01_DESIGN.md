# Aura Future Office 沉浸式高级设计文档

## 1. 项目定位与极致目标

**项目名称**: aura-future-office
**项目类型**: 纯前端静态沉浸式演示网站 (无后端)
**核心目标**: 面向非 IT 专业的普通业务人员，以**极其震撼的沉浸感 (Immersion)** 和**直觉级的视觉隐喻**，展示 Aura 平台与传统软件的根本差异。
**设计主轴**: 摈弃传统的“平铺直叙”幻灯片，引入**《像素与架构的系统共鸣》**底层理论，将格式塔心理学原则与顶级前沿 Web 技术深度交融。

---

## 2. 格式塔与沉浸式架构共鸣 (Gestalt & Architecture Resonance)

为了达到超一流水准的“电影级演示”沉浸感，本项目在视觉与动效层面设定以下强制性约束（参考 gestalt-resonator 标准）：

*   **GII (格式塔知觉完形指数 - 留白优先)**: 
    *   绝对禁止使用生硬、破碎的物理边框线 (Borders)。
    *   利用“接近性 (Proximity)”和严格的底层骨骼网格 (Grid Skeleton)，通过精确的 Padding/Margin 控制实现软性视觉切分。
*   **TPF (时序缓动与物理拟真度 - 拒绝线性)**:
    *   所有转场、页面切换和元素出场，必须引入基于“真实世界物理预期”的非线性缓动 (Cubic-bezier)。
    *   大量运用 Stagger (交错延迟) 动效，让内容揭示产生如水波纹般的“共同命运 (Common Fate)”呼吸感。
*   **COE (仅图层合成渲染优化 - 120fps 保障)**:
    *   **红线要求**：只要涉及动画，强制且唯一允许使用 `transform` (translate, scale, rotate) 与 `opacity` 属性。
    *   绝对禁止通过动画驱动 `width`, `height`, `top`, `left`，完全规避浏览器的重绘/重排，全程依托 GPU Composite 加速。
*   **全景深沉浸底座 (WebGL & Glassmorphism)**:
    *   采用暗黑/深空色系为锚点。底层背景铺设缓慢流转的 WebGL 粒子场或光影噪音，前景卡片采用带深度的拟物玻璃质感 (Glassmorphism)，营造空间节律。

## 3. 场景级视觉剧本 (Cinematic Scenario Scripts)

演示内容围绕“提出痛点 -> 揭示变革 -> 场景对比 -> 展望未来”展开，利用高级动效传达差异。

### 第一幕：愿景 (The Vision)
*   **视觉**: 深邃的 WebGL 动态星辉背景，中心聚拢的高密度紫翠色光芒。
*   **文案**: 主标题：“重塑日常：当 AI 成为你的最佳同事”
*   **动效**: 标题文字通过局部模糊与透明度变化 (Blur & Opacity)，以非线性的 Stagger 节奏粒子化聚合入场。

### 第二幕：刚性墙与柔性流 (The Paradigm Shift)
*   **传统痛点**:
    *   视觉暗示：高密度的灰暗信息块，像沉重的砖块一样僵硬堆叠，齿轮艰难咬合。
    *   文案：“传统软件：你必须去适应它设定的死板规则。”
*   **Aura 变革**:
    *   视觉暗示：一束灵动的紫色光束穿透灰暗区块，流体般的网格动态重组。
    *   文案：“人工智能 (Agent)：它来适应并拆解你的工作意图。”

### 第三幕：高密度场景对撞 (Scenarios Collision)

*   **场景 1：跨部门会议安排**
    *   **过去 (左侧)**: 沉重的日历、邮件、系统图标，需要人工连线。
    *   **Aura (右侧)**: “帮我约下周三下午和产品部的对齐会”。话音落下，AI 节点瞬间激活，光流并发闪烁，一根主线瞬间点亮所有分支。
*   **场景 2：差旅与财务报销**
    *   **过去 (左侧)**: 层叠的表单和带有“红色警告驳回”印章的文件缓慢传递。
    *   **Aura (右侧)**: 抛入发票截图，底层的规则引擎微动效开始运转，绿色合规进度条在 0.3 秒内平滑拉满。
*   **场景 3：新人入职与环境开通**
    *   **过去 (左侧)**: 孤立的信息孤岛闪烁，象征繁琐的工单切换。
    *   **Aura (右侧)**: “新同事 Alice 明天入职设计部”。如同石子投入水面，紫色的能量涟漪 (Scale & Opacity) 荡漾开来，自动激活周边的工具矩阵。
*   **场景 4：业务数据报告生成**
    *   **过去 (左侧)**: 人手在多个杂乱重叠的视窗间频繁闪跳。
    *   **Aura (右侧)**: “汇总本月获客成本并生成简报”。AI 光束直接穿透数据墙，多维度数据柱状体在 3D 空间中迅速升起并重组为一页精美简报。

### 第四幕：引擎解构与结语 (The Core & CTA)
*   **视觉**: 摒弃 UML 与代码。展示一个极简发光的“数字心脏”晶体引擎。
*   **内容**: 感知意图 (Understand) -> 规划路径 (Plan) -> 执行反馈 (Execute)，三个图标通过轨道光效循环运转。
*   **交互**: 伴随黎明曙光背景，发光的 CTA 按钮浮现：“探索未来工作流”。

## 4. 全局控件与国际化 (Global UI & i18n)

*   **悬浮控件层 (Z-Index Top)**:
    *   右上角或侧边栏提供极简的“多语言切换”悬浮按钮。
    *   支持**中、日、英 (ZH/JA/EN)** 三语无缝热切换。
    *   切换时，文本必须配合 `Framer Motion / GSAP` 的文字切片 (Text Split) 特效，丝滑过渡。

---

## 5. 沉浸式技术基座选型 (Advanced Tech Stack)

为了支撑严苛的 COE (图层合成优化) 和 TPF (物理拟真) 指标，技术架构必须升级：

1.  **框架底座**: **Vite + React (或 Vue 3)**（摒弃传统静态幻灯片框架，完全手写单页全屏滚动应用，以获得对 DOM 渲染的绝对控制）。
2.  **神级动效库**: 强制使用 **GSAP (GreenSock)** 配合 `ScrollTrigger` 实现基于滚动的复杂编排，或在 React 中深度使用 **Framer Motion**。
3.  **空间渲染层**: 引入 **Three.js** 或 `@react-three/fiber`，用于在底图层绘制流动的光晕、粒子交互与 3D 晶体隐喻。
4.  **样式工程**: **TailwindCSS** (用于极速原子化布局) + 自定义 CSS 变量 (注入 Gestalt 设计 Tokens)。
5.  **国际化**: `i18next` 或 `vue-i18n`。
